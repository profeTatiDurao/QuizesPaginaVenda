Footer, Social Icons & Copyright

Teste seus conhecimentos sobre espaçamentos abreviados (padding), colunas responsivas no rodapé, ícones de marcas e entidades especiais do HTML5!

1) 📏 Na regra do footer, escrevemos padding: 4rem 0 2rem; usando exatamente 3 valores. Qual é a ordem que o navegador aplica esses espaçamentos internos?

2) 🎈 [DESAFIO DE CÓDIGO] Quando o usuário passa o mouse nos ícones das redes sociais (.social-icons a:hover), eles ganham a cor principal e "flutuam" -5px para cima. Complete a função de transform:

style.css — Efeito Hover Social CSS3
.social-icons a:hover {
  background-color: var(--primary);
  transform: (-5px); /* Move 5px para cima */
}

3) 🏷️ Observe as classes do Font Awesome no rodapé: nos ícones sociais usamos class="fab fa-instagram", mas no contato usamos class="fas fa-phone". Por que o prefixo muda de fas para fab?

4) 📱 No .footer-content temos 4 colunas (.footer-column) com grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));. O que acontece automaticamente quando o site é aberto em um celular estreito?

5) ©️ [DESAFIO DE CÓDIGO] Na área de direitos autorais (.copyright), usamos uma HTML Entity para exibir o símbolo © sem risco de bug de acentuação. Complete o código da entidade abaixo:

index.html — Linha de Copyright HTML5
<div class="copyright">
  <p>&; 2023 TechStore Pro - Todos os direitos reservados.</p>
</div>
