Scroll & Galeria

Domine o fluxo de imagens, Flexbox quebrado (Wrap), Scroll Horizontal e a arte de domar o Scrollbar do navegador!

Q: 0/10

1) Na .equipe-grid, usamos display: flex; e em seguida flex-wrap: wrap;. O que o flex-wrap faz exatamente com os cartões da equipe?

2) Na foto arredondada (.foto-membro), usamos border-radius: 50%; para fazer um círculo. Por que também precisamos colocar object-fit: cover;?

3) No CSS, temos a regra .fundo-escuro .titulo-secao que altera a cor do texto do título. Por que escrevemos essas duas classes juntas (separadas por espaço)?

4) 🖼️ Na .galeria-fotos, não usamos flex-wrap: wrap;. Em vez disso, usamos overflow-x: auto;. O que isso gera na página?

5) 💻 [CÓDIGO] Para organizar a galeria em linha reta (lado a lado), qual propriedade usamos no container .galeria-fotos antes de colocar o overflow?

style.css — Galeria
.galeria-fotos {
  display: ;
  gap: 20px;
  overflow-x: auto;
}

6) Para personalizar a espessura da barra de rolagem da nossa galeria horizontal, o professor alterou a propriedade height no pseudo-elemento ::-webkit-scrollbar. Se a galeria fosse vertical (rolando para cima/baixo), o que ele mudaria?

7) 💻 [CÓDIGO] Qual é o nome do pseudo-elemento CSS (a parte após os dois pontos duplos) que usamos para pintar o fundo estático (trilho) por onde a barra de rolagem desliza?

style.css — Scrollbar
.galeria-fotos:: {
  background: #222; /* Cor do trilho */
}

8) 💻 [CÓDIGO] E como chamamos a parte da barra que se move (o controle deslizante) que nós pintamos com a cor principal (var(--primary))?

style.css — Scrollbar
.galeria-fotos:: {
  background-color: var(--primary);
}

9) Nas fotos da .galeria-fotos img, travamos a altura em 250px (height), mas não definimos a largura (width). O que acontece com a largura das fotos originais?

10) Observação importante: Os prefixos ::-webkit-scrollbar, -track e -thumb funcionam perfeitamente no Google Chrome, Edge e Safari. Qual grande navegador atual não suporta esses prefixos -webkit- para scrollbars?
